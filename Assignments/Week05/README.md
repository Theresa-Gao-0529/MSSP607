# MSSP6070 Participation Activity Week 5

## Folder structure

- `Data/` contains the five source stock CSV files.
- `notebook_week05.ipynb` contains the Week 5 Pandas exercise.
- `Data/faanf.csv` is generated by running the notebook.

## Colab

Open `notebook_week05.ipynb` in Google Colab and run all cells from top to bottom. The notebook reads the files from `Data/`, adds the ticker symbol, appends the five DataFrames, saves `Data/faanf.csv`, converts `date` and `volume`, sorts by `date` and `ticker`, finds the seven largest volume rows, and uses `melt()` with `date` and `ticker` as identifiers.
